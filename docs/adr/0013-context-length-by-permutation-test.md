# ADR-0013: コーパスの文脈の長さを、距離を置いた2単位の相互情報量と、組の並べ替えとの比較で調べる

- 番号: ADR-0013
- 日付: 2026-11-15（PRの日付）
- 状態: 採用

## 背景

ADR-0012のn-gramの表で、『吾輩は猫である』全文の文節の読みの系列は、1次でも統計が足りない（続きが1種類の文脈の出現の割合が37.85%、上限は10%）と分かった。かなの系列は2次まで足りる。
言語の側の統計として、文脈がどこまで次の単位の予測に情報を持つかと、コーパスを小さくした時にその長さと統計が足りているかの割合がどう動くかを、数値で読める形にする必要がある（issue #100）。標準のコーパスは猫のまま変えない。

## 決定

- 量は、距離 `d` だけ離れた2単位の相互情報量 `I(d)` にする。走りの中だけで組を数え、出現回数の比で確率を求める
- 基準は、距離ごとに、組の2つ目だけを全組の間で並べ替えた列にする。組の1つ目と2つ目の周辺分布と組の数が元と同じなので、出現回数の比で出す相互情報量の偏りが元と等しい。2変数の独立性の並べ替え検定の標準の形である
- 並べ替えは全体の表で199通り（種 `1`〜`199`）、コーパスの大きさを変えた表の `1/16`〜`1/2` で99通り（種 `1`〜`99`、実行時間を抑えるため）。p値は `(1 + 元以上になった通りの数) / (通り数 + 1)`。p値が0.05以下の距離を、依存を検出できた距離とする
- 距離は格子（`1`〜`8` の全部と、`12`・`16`・`24`・`32`・`48`・`64`。文節の系列は `32` まで）で、全点のp値を出す。検出できた文脈の長さは、格子の点で検出が途切れずに続く最大の格子点
- 読む主体は、距離ごとの `I(d)`・基準の平均・超過量・p値・`d = 1` の超過量に対する比の表にする。長さの1つの値は、p値が0.05の近くの距離で並べ替えの種によって変わるので、受け入れ条件のために併記する
- Grassbergerの推定量（Lin & Tegmark (2017) の付録Dが使う補正）で出した相互情報量を、元の組と種1で並べ替えた組の両方で、参考の列として出す。検出には使わない
- コーパスの大きさは、走りを単位に無作為に選んで変える（かなの単位の数の `1/16`〜`1/2`、種5通り）。走りを選ぶ種の生成器と、並べ替えの種の生成器は、別の列にする
- 測った値は結果として出すだけにする。外挿でコーパスの必要な大きさを見積もる式と、閾値で結論を出す判定は作らない

定義は `docs/corpus-ngram.md` の「文脈の長さの推定」。実装は `interpretation/corpus-context.ts`。

## 却下した案

| 案 | 採らなかった理由 |
|---|---|
| 次数ごとの条件付きエントロピーを、出現回数の比で計算し、減らなくなる次数を文脈の長さとする | 統計が足りない次数では、文脈がほぼ1回しか出ないので、条件付きエントロピーが0へ向かって減り続ける。文節の系列は1次で統計が足りないので、長さを過大に出す |
| コーパスを学習と評価に分け、平滑化したn-gramモデルの評価側の交差エントロピーが最小になる次数を取る | 平滑化の方法と係数で結果が変わり、その選択が測る量に入る。統計が足りているかの量と、文脈の長さの量が分けられなくなる |
| 相互情報量の偏りを、解析的な補正（Miller–Madowなど）で差し引く | 補正は、組の数が組の種類より十分多い時の近似で、ほとんどの組が1回だけの文節の系列では成り立たない。並べ替えた基準は、近似を置かずに同じ偏りを持つ |
| Grassbergerの推定量で偏りを補正して、0との差で判定する | 並べ替えた組でも0から離れる。猫全文の文節の系列で、種1で並べ替えた組の値は `d = 1` で11.356ビット、`d = 32` で11.446ビット（種1の1通り）。かなの系列は0.009〜0.014ビット。補正が疎な組で足りないので、参考の列に留める |
| 全走りの単位を1列に並べ替えて、元の走りの長さで切り直す | 距離 `d` の組は `d` より長い走りからしか取られず、長い走りの単位の分布は全体と違うので、組の周辺分布が元とそろわず、偏りが違う。PR #868のレビューで、文節の系列の超過量が `d = 32` で約 −0.1ビットになった。20通りの最大と比べる規則は、p値が数%の距離で種の組によって検出が変わった |
| 走りの中だけで単位を並べ替える基準と、走りの中だけで組の2つ目を並べ替える基準 | 同じ走りの組成による依存を全距離に一様に持ち込む。元の近い距離ほど強い組成の依存と比べて、遠い距離の超過量が負に出る。組の2つ目を走りの中で並べ替えた基準で、かなの `d ≥ 12`、文節の `d ≥ 3` では、39通りのほぼ全部が元以上だった（種1〜39の試算） |
| 長さが `d` を超える走りだけの単位を並べ替える基準 | 周辺分布は近づくが、組の1つ目は走りの頭寄り、2つ目は走りの末尾寄りから取られるので、まだそろわない。文節の `d ≥ 8` の超過量が負になった（試算） |
| 並べ替えの代わりに、生成文（#101）や外部のコーパスで比べる | 生成文の依存は表の統計だけで決まるので、元の系列の依存を測る独立した基準にならない。外部のコーパスは、標準のコーパスを変えない決定に反する |

## 結果

- 距離モデルの値・回帰の記録は動かさない
- 『吾輩は猫である』全文（全体の表。並べ替え199通り、種 `1`〜`199`、p値の上限0.05）:
  - 文節の系列の超過量は、`d = 1` で0.122ビット、`d = 2` で0.021、`d = 3` で0.011、`d = 8` で0.002、`d = 16` で0.002、`d = 32` で約0.00004（`d = 1` の超過量の0.0003倍）。p値は `d = 16` で0.045、`d = 24` で0.070、`d = 32` で0.435。長さは16
  - かなの系列は `d = 64` まで、p値が0.05以下だった。超過量は `d = 1` で0.922ビット、`d = 16` で約0.002ビット、`d = 24`〜`64` で約0.001ビットで、遠い距離で減らない。長さは64（上限まで検出）
  - 値は `scripts/corpus-ngram-tables.ts --context` の出力。大きさを変えた表は並べ替え99通り（種 `1`〜`99`）
- 2単位の組だけを見るので、検出できた長さは文脈が情報を持つ長さの下限の目安で、n-gramの表の次数を決める量ではない。基準は組の周辺分布をそろえるが、走りごとの単位の組成と話題による依存は残る。遠い距離の小さい超過量は、文法でなく組成に由来しうる。限界は `docs/corpus-ngram.md` に書いた
