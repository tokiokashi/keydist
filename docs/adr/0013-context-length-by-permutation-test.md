# ADR-0013: コーパスの文脈の長さを、距離を置いた2単位の相互情報量と、並べ替えた系列との比較で推定する

- 番号: ADR-0013
- 日付: 2026-11-15（PRの日付）
- 状態: 採用

## 背景

ADR-0012のn-gramの表で、『吾輩は猫である』全文の文節の読みの系列は、1次でも統計が足りない（続きが1種類の文脈の出現の割合が37.85%、上限は10%）と分かった。かなの系列は2次まで足りる。
言語の側の統計として、文脈がどこまで次の単位の予測に情報を持つかと、コーパスを小さくした時にその長さと統計が足りているかの割合がどう動くかを、数値で読める形にする必要がある（issue #100）。標準のコーパスは猫のまま変えない。

## 決定

- 量は、距離 `d` だけ離れた2単位の相互情報量 `I(d)` にする。走りの中だけで組を数え、出現回数の比で確率を求める
- 出現回数の比による相互情報量の偏りは、単位を並べ替えて依存を壊した系列（種 `1`〜`20` の20通り）の `I(d)` と比べて扱う。元の `I(d)` が20通りすべてを上回った距離を、検出できた距離とする
- 検出できた文脈の長さは、`d = 1` から検出が途切れずに続く最大の `d`
- コーパスの大きさは、走りを単位に無作為に選んで変える（かなの単位の数の `1/16`〜`1/2`、種5通り）。走りを選ぶ種の生成器と、並べ替えの種の生成器は、別の列にする
- 測った値は結果として出すだけにする。外挿でコーパスの必要な大きさを見積もる式と、閾値で結論を出す判定は作らない

定義は `docs/corpus-ngram.md` の「文脈の長さの推定」。実装は `interpretation/corpus-context.ts`。

## 却下した案

| 案 | 採らなかった理由 |
|---|---|
| 次数ごとの条件付きエントロピーを、出現回数の比で計算し、減らなくなる次数を文脈の長さとする | 統計が足りない次数では、文脈がほぼ1回しか出ないので、条件付きエントロピーが0へ向かって減り続ける。文節の系列は1次で統計が足りないので、長さを過大に出す |
| コーパスを学習と評価に分け、平滑化したn-gramモデルの評価側の交差エントロピーが最小になる次数を取る | 平滑化の方法と係数で結果が変わり、その選択が測る量に入る。統計が足りているかの量と、文脈の長さの量が分けられなくなる |
| 相互情報量の偏りを、解析的な補正（Miller–Madowなど）で差し引く | 補正は、組の数が組の種類より十分多い時の近似で、ほとんどの組が1回だけの文節の系列では成り立たない。並べ替えた基準は、近似を置かずに同じ偏りを持つ |
| 並べ替えの代わりに、生成文（#101）や外部のコーパスで比べる | 生成文は #101で作る。外部のコーパスは、標準のコーパスを変えない決定に反する |

## 結果

- 距離モデルの値・回帰の記録は動かさない
- 2単位の組だけを見るので、検出できた長さは文脈が情報を持つ長さの下限の目安で、n-gramの表の次数を決める量ではない。並べ替えた基準は単位の出現回数だけを保つので、話題による偏りも依存として検出される。限界は `docs/corpus-ngram.md` に書いた
- 『吾輩は猫である』全文では、かなの系列は `d = 23` まで、文節の系列は `d = 2` まで検出できた（`scripts/corpus-ngram-tables.ts --context` の出力）
