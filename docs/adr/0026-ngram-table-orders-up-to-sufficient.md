# ADR-0026: 選べる表の次数を、統計が足りている最大の次数までにし、0次は常に選べる

- 番号: ADR-0026
- 日付: 2026-11-28（PRの日付）
- 状態: 採用

## 背景

表による解析で利用者が選べる次数の上限は、表の元のテキストがその次数の統計を数えきれているかで決める（issue #96）。判定の量は `docs/corpus-ngram.md` の、続きが1種類しか無い文脈の出現の割合（上限0.1）である。
この量は0次では決まらない（文脈で条件付けないため）。標準のコーパス（『吾輩は猫である』全文）の文節の読みの系列は、1次の割合が37.85%で上限を超え、足りている最大の次数が無い（`scripts/corpus-ngram-tables.ts --max-order 4` の出力）。

## 決定

- 選べる次数は、0次から、足りている最大の次数 `K` まで。`K` が無ければ0次だけ（§13.5）
- 0次は、判定の量が決まらないので判定しない。0次は文節ごとの出現回数だけを使い、文脈と続きの関係を使わないので、統計が足りないという理由では外さず、常に選べる
- `K` を超える次数は、計算できても選べる範囲に入れない。スクリプトは `--reference-orders` で、選べない次数を参考として別の見出しで出す
- 表の次数の既定は、選べる次数の最大（`K`、無ければ0）。表の元のテキストによって既定が変わる

## 却下した案

| 案 | 却下の理由 |
|---|---|
| 0次を選べる範囲から外し、1次以上だけにする | 標準のコーパスでは選べる次数が無くなり、表による解析が使えない |
| 既定を固定の次数（1次）にする | 標準のコーパスの1次は上限を超えている。選べない次数を既定にすることになる |
| 閾値の割合を結果に合わせて緩める | `docs/corpus-ngram.md` が、上限0.1を結果を見る前に固定し、結果に合わせて動かさないとしている |
| 上限を超えた次数も、注意書きを付けて選べるようにする | 続きが1種類に決まる位置が多い次数は、文節の並びの記憶に近づく。選べる範囲に入れると、判定の量が決めた上限が意味を持たなくなる |

## 結果

- 標準のコーパスでは、選べる表の次数は0次だけで、文節の先読み `N` は結果を変えない（§13.3）。`N` の選べる範囲と既定値は次数で変えないので、利用者のテキストの表で次数が上がる時に、そのまま使える
- 1次以上の結果は、選べない次数の参考としてだけ出る。値を読む時は、上限を超えた次数であることを併記して読む
