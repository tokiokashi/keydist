# ADR-0029: 表による解析が出す量は、総量・かなあたりの値と、割った分布・割らない分布の2通りにする

- 番号: ADR-0029
- 日付: 2026-11-28（PRの日付）
- 状態: 採用

## 背景

issue #96の2026-10-25の決定は、結果に総移動距離と入力文字あたりの値に加えて、文節ごとの移動距離の分布を出すとした。分布の形は、文節の長さで割るか、割る時の長さをモーラとかなのどちらで数えるかを、実装の時に決めるとしていた。

## 決定

- 総移動距離 `D` と入力かな数 `C`、入力1かなあたり `D / C`、打てなかった文字を出す（§13.2）
- 文節ごとの移動距離の分布は、文節の距離そのままと、文節のかな数で割った値の2通りを出す。分布は出現回数の重みで、10%・25%・50%・75%・90%点（重みの累積が `⌈q · W⌉` に達する最初の値。補間しない）と、最小・最大・平均で出す
- 長さはかなで数える。§4.6の入力かな数・§7 R3の位置と同じ単位で、`C` と分母がそろう
- 文節の移動距離と出現頻度の関係は、このissueでは出さない（issue #96の決定）。配列の優劣・順位・合成スコアも出さない

## 却下した案

| 案 | 却下の理由 |
|---|---|
| 割った分布だけ出す | 1かなの文節は値が打鍵1つに偏る。割った分布だけでは、長さの影響を除く代わりに、短い文節の値が分布の形を決める |
| 割らない分布だけ出す | 長い文節ほど距離が大きくなり、長さの違いと打ちやすさの違いが混ざる |
| モーラで数える | 拗音の `ゃゅょ` と、撥音・促音・長音の扱いの規則を足す必要がある。`C` と分母がそろわない |
| 分位点を補間して出す | 観測した値のどれかになる分位点の方が、導出を追える。`docs/segment-metrics.md` の90%点と同じ理由 |

## 結果

- 2つの分布は一方が他方を置き換えない。どちらも平均は、項目の重みの付いた平均で、`D / C`（かなの数で重み付けした平均）とは違う量になる
