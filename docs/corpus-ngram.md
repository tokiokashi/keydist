# コーパスの文節の読みとかなのn-gramの表と、統計が足りているかの量

コーパス（青空文庫の作品など、漢字かな混じりのテキスト）から、言語の側の統計として、次数ごとのn-gramの表を2種類作り、次数ごとに統計が足りているかを見る量を出す定義。
2種類は、文節の読みの系列（単位は文節1つの読み）と、かなの系列（単位はコードポイント1つ）。同じコーパス・同じ前処理・同じ切れ目で数えるので、並べて比べられる。
実装は `src/interpretation/ngram-table.ts`（数え方。`docs/kana-chain-comparison.md` の表と同じ定義を単位が文字列の系列へ一般化した）と `src/interpretation/corpus-ngram.ts`（系列の作り方と量）、
実行は `scripts/corpus-ngram-tables.ts`（結果をMarkdownの表で出す）。画面には出さない。
処理は配列の定義を参照せず、品詞を使わない。出現回数をそのまま重みにする以外の重みと、配列の良し悪しを決める基準は作らない。距離モデルの値（`spec/distance-model.md`）は変えない。

## 入力

コーパスの原文と、原文の文節の区切りから、次の3つを作る。同じ関数に別のテキストを渡せば、別のコーパスの表になる。

1. **読みのテキスト。** 原文を形態素解析し、漢字を含む語を辞書の読みに置き換えたテキスト（`spec/distance-model.md` §4.6の1段目と同じ。利用者の読みの直しは当てない）。
2. **文節の区切り。** 分割器を、読みに直す前の原文に1回だけ当てる（読みに直した後のかなの列を分割器に通さない）。区切りは、`docs/segment-metrics.md` の「文節の区切り」の1と2と同じ処理（`mapBoundariesToReading`）で読みのテキストの位置へ写す。
   区切りが漢字を読みに直した語の途中に来た時は、その語の後ろの境目へ寄せる。1語の読みを2つの文節に分けない。
3. **前処理。** §4.6の2段目から4段目のうち、配列を参照せずに決まる分だけを、読みのテキストと区切りの両方に当てる。
   - 当てる: 記号の取り除き（既定の範囲。`、` `。` だけを残す）と、英字と数字の取り除き。半角の `,` `.` は、配列が持たない場合の書き換え（`、` `。`）に統一する。`prepareEvaluationText` を、配列が `,` `.` を持たない条件で呼ぶ
   - 当てない: 片仮名のひらがなへの書き換え（5段目）。書き換える範囲が配列の見出しで変わるので、表は片仮名とひらがなを別の文字として数える
   - 区切りは、取り除いた記号の分だけ前へ詰める（`evaluationBoundaries`）

## 系列

前処理の後のテキストを、次の文字で切って、系列の集まり（走り）にする。n-gramは1つの走りの中だけで数え、走りをまたぐ並びと、切った文字を飛ばしてつなげた並びは作らない。

- **空白と改行。** 段落の境目と空白は、言語の内容ではないので切る。段落をまたいだ文節の組は数えない
- **読みに直せなかった漢字と、かなでない文字。** 辞書に読みが無い語の漢字は、読みに直らずに残る（§4.6の1段目）。ギリシャ文字のように、記号でも英字でもなく前処理の後も残る文字もある。系列に入れるのは、ひらがな・片仮名・長音・濁点と半濁点の結合文字と、前処理が残す `、` `。` だけにして、それ以外の文字で切る。読みの無い文字を単位に入れると、文節の読みでもかなでもなくなる。除いてつなぐと、実際には隣り合わない文字の並びができる
- **文の区切り（`。` `、`）。** 切らない。打鍵では続けて打つ文字で、評価に渡すテキストにも1文字として残る。`。` `、` はかなの系列では1文字の単位、文節の系列ではその文節の読みの末尾の文字になる
- **打てない文字。** 配列で変わるので、表は区別しない（`docs/kana-chain-comparison.md` と同じ）。切るのは上の、配列に依らず決まる文字だけ

文節の読みの系列は、走りの中を、文節の区切りと切った文字で分けた断片の列で、断片は読みの文字列。文節が空白や読みの無い文字をまたいでいた時は、その箇所で2つの断片になる。
かなの系列は、同じ走りの中のコードポイントの列。2つの系列は、同じ文字を同じ走りに入れる。

## 表

次数 `r` の表は、1つの走りの中の連続する `r + 1` 単位の並びと、全走りを通した出現回数を持つ（0次は単位ごとの出現回数）。
鍵は、かなの系列は文字を続けて書いた文字列、文節の系列は文節の読みを `U+0000` でつないだ文字列。前処理が制御文字を取り除くので、読みは `U+0000` を含まない。
つなぎ目を入れるので、`ab|c` と `a|bc` のような区切りの違う並びが同じ鍵にならない。単位が `U+0000` を含む時は例外を投げる。

## 統計が足りているかの量

次数 `r` の表について、並びの先頭の `r` 単位を**文脈**、最後の1単位を続きと呼ぶ。0次の文脈は空で、全体で1つ。

| 量 | 定義 |
|---|---|
| 出現数 `N` | 表の出現回数の合計（走りの中で `r + 1` 単位がそろう位置の数） |
| 並びの種類 | 表のキーの数 |
| 1回だけの並び | 出現回数が1の並びの数 |
| 文脈の種類 | 並びの先頭 `r` 単位の種類の数 |
| 続きが1種類の文脈の出現 | 続きが1種類しか無い文脈について、その文脈の出現回数（その文脈で始まる並びの出現回数の合計）を足した数 |
| 続きが1種類の文脈の出現の割合 | 続きが1種類の文脈の出現 / `N`。判定に使う量 |
| 文脈が1回だけの数 `N₁` | 文脈の出現回数が1の文脈の数 |
| 文脈が1回だけの割合 | `N₁ / N`。参考の量 |
| 並びが1回だけの割合 | 1回だけの並びの数 / `N`。参考の量 |

0次の文脈は空で全体で1つなので、文脈で条件付けた量（続きが1種類の文脈の出現の割合と、文脈が1回だけの割合）は決めない。0次の語彙の統計は、並びが1回だけの割合で見る。

**判定に使う量。** 続きが1種類しか無い文脈の出現の割合を使う。その文脈が出た位置では続きが1つに決まるので、続きが決まった位置が多いほど、生成文は原文の写しに近づく。
`docs/kana-chain-comparison.md` の「候補が1つの段」（生成の手順1で、文脈に続く文字の種類が1つだけだった段）は、この現象を生成した文で数えた量で、表から出す割合は、文脈の出現で重みを付けた同じ現象の量にあたる。
文脈が何回出ていても、続きが1種類なら数える。

**参考の量。** 文脈が1回だけの割合は、Good-Turing推定（*Biometrika* 40: 237–264 の1953年の論文。`N₁/N` を未出現の確率の推定とする形は、1995年の論文 "Good–Turing frequency estimation without tears"（*Journal of Quantitative Linguistics* 2: 217–237）に載っている）を、並びではなく文脈へ当てたもの。
同じ作品の続きから次の位置を1つ取った時、その位置の文脈が、ここまでに一度も出ていない確率の推定になる。
文脈が1回しか出ないと続きは1種類に決まるので、続きが1種類の文脈の出現の割合は、文脈が1回だけの割合以上になる。逆は成り立たない。何回か出ても、続きが1種類の文脈がある。
次数 `r` の文脈が1回だけの割合は、次数 `r − 1` の並びが1回だけの割合と、ほぼ同じ量になる（次数 `r` の文脈は、次数 `r − 1` の並びだから。出現数 `N` が走りの端の分だけ違う）。判定には使わない。

**足りている次数。** 続きが1種類の文脈の出現の割合が上限 `0.1` 以下の次数を、統計が足りている次数とする。1次から順に見て、最初に上限を超えた次数の手前までの最大の次数を「足りている最大の次数」として出す。
0次は判定しない。1次で上限を超えた時は、足りている次数が無いと出す。どの次数の割合も、足りているかにかかわらず出す。

- 上限 `0.1` は、`docs/kana-chain-comparison.md` の「候補が1つの段の割合」の上限と、同じ現象の量なので同じ値を持ち越した。結果を見る前に固定した。先行研究に、この量の標準の閾値は確認できていない。値の根拠は、同じ文書の上限と値をそろえることだけで、`0.1` が最適だという根拠は無い。結果に合わせて動かさない
- 割合はコーパスの大きさと同質さに依る。1作品（明治期の小説、一人称の語り）から出た値は、ほかの時代・ジャンルの文章に当てはまる保証が無い。同じ作品の中でも、固有名詞や繰り返しの多い章では偏る
- 表から出す割合は、生成した段の割合と数え方が違う。生成は文脈の出現で重みを付けて続きを引き、手順2と3の段も数えるので、2つの値は一致しない。上限を持ち越すのは、同じ現象を見る量として扱うためで、同じ値になるからではない
- Good-Turing推定は、標本が独立に引かれることを前提にする。文章は同じ語が近くで繰り返されるので、文脈が1回だけの割合は未出現の確率をやや低く見積もる向きに偏りうる。偏りの大きさは測っていない
- 次数が上がるほど、続きが1種類の文脈の出現の割合は増える（長い文脈は出現が減る）。上限を超えた次数より上の次数は、表は作れるが、言語の側の統計として使わない目安にする
- この量は、統計が足りているかだけを見る。文脈の長さの推定と、生成文の自然さは、この量で判定しない（生成文が自然に読めることは、統計が足りない高い次数でも起きる）

## 再現の条件

結果に次を併記する。

- コーパスの版（zipのファイル名とsha256）と、記法を除いた全文のsha256
- 前処理（上の「入力」の3）と、切った文字の数（空白と改行、読みに直せなかった漢字、かなと句読点でないその他の文字）
- 文節の分割器の名前と版
- 読みに直した辞書と解析器の名前と版
- 表の最大の次数と、足りているかの上限
- 統計が1作品のコーパスから出たものであること。ジャンルの区分は無い。標準のコーパスが1作品（明治期の小説、一人称の語り）である限り、日本語の文章一般の統計として読まない
