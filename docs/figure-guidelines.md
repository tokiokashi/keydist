# 図の補助線と軸の説明

散布図など、2つの量を軸に取る図に補助線を引く時と、軸の量を説明する時の決まり。
数値の扱い全般は `AGENTS.md` の「数値を扱う時・外に出す時」に従う。

## 補助線

- 補助線は、読み手の理解を助けるものに限って引く。恒等式で決まる量の線に限らず、50%の線のような基準の位置の線も引いてよい
- 恒等式の線を引くのは、線の量そのものが読んで意味を取れ、同じ線の上で値を比べた時に、同じテキストを打つ時の量と取り違えない時に限る
  - 総移動距離を、配列ごとに違う回数（キー数・移動ありキー数・アクション数）で割った値とその逆数の線は引かない。線の上で値が小さい側にいても、同じテキストを打つ時の距離は大きいことがある
  - 線を引くためだけに新しい指標を足さない
- ツールが用意する組み合わせも、利用者が軸を選ぶ図も、誤読される線を引かない。読み方の注意を書いて線を残すことはしない
- 点の並びから関係の強さを測る線（回帰直線など）と係数は出さない

## 軸の量の説明

- 軸の2つの量が恒等式で3つ目の量と結ばれるのに線を引かない時は、軸の量の説明で3つの量の関係を書く
- 恒等式が無くても2軸が同じものから作られている時（同じキーを左右に分けた割合など）は、軸の量の説明でそのことを書く
