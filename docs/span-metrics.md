# 文字範囲ごとの指標の集計

Run Chart（テキスト上の位置ごとの推移）が使う集計の定義。実装は `src/interpretation/span-metrics.ts`。
距離モデルの値（`spec/distance-model.md`）は変えない。`computeTraceScalars`（`src/interpretation/metrics.ts`）と同じ分子と分母の定義を、文字の範囲に区切って足し直す。

## 範囲と文字位置

範囲は、評価に渡したテキストの文字位置の半開区間 `[a, b)`。文字位置は `Stroke.kanaStart` と同じ数え方で、先頭が0、
打鍵できなかった文字も1文字に数える（`Trace.inputChars` は `[...text].length`）。

## 分子と分母

| 指標 | 分子 | 分母 |
|---|---|---|
| 1文字あたりの距離 `perCharUnits` | 範囲に帰属したステップの距離 [u] の和 | 範囲の文字数 `b − a` |
| 1文字あたりの打鍵数 `perCharSteps` | 範囲に帰属したステップの数 | 範囲の文字数 `b − a` |
| 1打鍵あたりの距離 `meanPerStroke` | 範囲に帰属したステップの距離 [u] の和 | 範囲に帰属したステップの数 |
| 同指率 `sameFingerRate` | 範囲に帰属したステップの、同指の押下（`press.sfb`）の数の和 | 範囲に帰属したステップの数 |

同指率は割合（0〜1）のまま持ち、%への換算（100倍）は表示が行う。`computeTraceScalars` の同指率は、ステップ数が0の時に分母を1として扱うので、
全体の値は一致するが、範囲の分母が0の時は値が決まらないものとして扱う（0として描かない。図は線を切る）。

どの指標も「範囲の分子の和 / 範囲の分母の和」で書ける。テキストを重ならない範囲に分けて分子と分母をそれぞれ足すと、全体の分子と分母（`computeTraceScalars` の値）に戻る。
このため、範囲から作る値を足し合わせる側で再計算する必要が無い。

## ステップの帰属

各ステップ（`Stroke`）の距離・打鍵数・同指の数は、そのステップの `kanaEnd` の文字位置に帰属させる。
範囲の境目をまたぐ入力も、`kanaEnd` を含む範囲にだけ入る。ローマ字配列で別の入力の選択どうしの `kanaStart` から `kanaEnd` が重なっても、
各ステップは1か所にしか入らないので二重に数えない。

## 点と集計窓

Run Chartの点は、1回の入力の選択（同じ `selectionIndex` のステップの組）ごとに1つ置く。`inputIndex` はローマ字配列で別の選択どうしが共有するので、点の単位には使わない。
組の中の `kanaEnd` の最大を `e` とし、点の横位置は文字位置 `e`、値は範囲 `[e − W + 1, e + 1)` の値（`W` は集計窓の文字数）。
テキストの先頭で `W` 文字に満たない所は、ある分の文字で求め、目安線もその長さで求める。同じ `e` を持つ組が複数ある時は、`e` ごとに点を1つにまとめる。

画面の横軸は、点が覆う最後の文字の右端（`e + 1`、つまり「何文字目まで」）で目盛る。読み上げと吹き出しは、先頭を1とした「`e + 1` 文字目」と書く。
打鍵再生へ渡す文字位置は `e`（先頭が0）で、打鍵再生は `e` を `kanaStart` から `kanaEnd` に含む最初のステップへ移る。

## 中心線と目安線

中心線は、その配列のテキスト全体の値（`computeTraceScalars` の値と一致する）。

目安線は、中心線 `c` から上下に `3·s/√D` の位置に引く。`D` は範囲の分母（文字の指標では文字数、打鍵の指標ではステップ数）、
`s² = Σ(x_i − c)² / n` はテキスト全体から求めた、分母1つあたりの分子のばらつき。

- 文字の指標: `i` は文字位置（`n` = `inputChars`）、`x_i` はその文字位置に帰属した分子（距離またはステップ数。打鍵できなかった文字と、入力の途中の文字では0）
- 打鍵の指標: `i` はステップ（`n` = ステップ数）、`x_i` はそのステップの距離、またはそのステップの同指の押下の数
- 同指率で、どのステップの同指の押下の数も0か1の時は `s² = p(1 − p)`（`p` は全体の同指の割合）になる。同時押しなどで1ステップの同指の押下が2以上になるテキストでは一致しない

指標は0以上の量なので、下側の目安線は0より下に引かない。

目安線は統計的な保証ではない。範囲どうしは重なっていて独立ではなく、打鍵どうしにも相関がある。外れている箇所を探す手がかりとして使う。
係数3は目安線の幅を決める定数で、設定にはしない。
